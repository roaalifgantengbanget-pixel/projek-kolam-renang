═══════════════════════════════════════════════════════════════

✅ SOLUSI 1: Menggunakan GitHub CLI (Recommended)

1. Install GitHub CLI:
   Download dari: https://cli.github.com/

2. Login ke GitHub:
   gh auth login

3. Push ke repository:
   cd nextjs-usaha
   git push -u origin main

═══════════════════════════════════════════════════════════════

✅ SOLUSI 2: Menggunakan Personal Access Token

1. Buat Token di GitHub:
   - Buka: https://github.com/settings/tokens
   - Klik "Generate new token (classic)"
   - Pilih scope: repo (full control)
   - Copy token yang dihasilkan

2. Push dengan token:
   git remote set-url origin https://TOKEN@github.com/roaalifgantengbanget-pixel/orang-hitam.git
   git push -u origin main

   (Ganti TOKEN dengan token Anda)

═══════════════════════════════════════════════════════════════

✅ SOLUSI 3: Menggunakan SSH Key

1. Generate SSH Key:
   ssh-keygen -t ed25519 -C "email@example.com"

2. Copy public key:
   cat ~/.ssh/id_ed25519.pub

3. Tambahkan ke GitHub:
   - Buka: https://github.com/settings/keys
   - Klik "New SSH key"
   - Paste public key

4. Ubah remote URL:
   git remote set-url origin git@github.com:roaalifgantengbanget-pixel/orang-hitam.git
   git push -u origin main

═══════════════════════════════════════════════════════════════

✅ SOLUSI 4: Upload Manual via GitHub Web

1. Buka: https://github.com/roaalifgantengbanget-pixel/orang-hitam
2. Klik "Add file" → "Upload files"
3. Drag & drop semua file dari folder nextjs-usaha
4. Commit changes
