🎯 CARA 1: DEPLOY DENGAN VERCEL CLI (TERCEPAT!)

1. Login ke Vercel:
   vercel login

2. Deploy:
   cd nextjs-usaha
   vercel

3. Ikuti prompt:
   ? Set up and deploy "nextjs-usaha"? [Y/n] Y
   ? Which scope? [Pilih account Anda]
   ? Link to existing project? [N]
   ? What's your project's name? projek-kolam-renang
   ? In which directory is your code located? ./
   
4. Deploy production:
   vercel --prod

5. SELESAI! 🎉
   Website Anda akan online di:
   https://projek-kolam-renang.vercel.app

═══════════════════════════════════════════════════════════════

🌐 CARA 2: DEPLOY LEWAT WEBSITE VERCEL (MUDAH!)

1. Buka: https://vercel.com

2. Klik "Sign Up" atau "Login"
   → Pilih "Continue with GitHub"

3. Setelah login, klik "Add New..."
   → Pilih "Project"

4. Import Repository:
   → Cari: roaalifgantengbanget-pixel/projek-kolam-renang
   → Klik "Import"

5. Configure Project:
   Framework Preset: Next.js ✓ (otomatis terdeteksi)
   Root Directory: ./
   Build Command: npm run build ✓ (otomatis)
   Output Directory: .next ✓ (otomatis)
   Install Command: npm install ✓ (otomatis)
   
   → Klik "Deploy"

6. Tunggu 1-2 menit...
   ⏳ Building...
   ⏳ Deploying...

7. SELESAI! 🎉
   ✅ Deployment Complete!
   
   Website Anda online di:
   https://projek-kolam-renang.vercel.app
   atau
   https://projek-kolam-renang-xxx.vercel.app

🔄 CARA UPDATE WEBSITE NANTI:

Setiap kali Anda push ke GitHub, Vercel otomatis deploy ulang!

⚙️ ENVIRONMENT VARIABLES (OPSIONAL):

Jika butuh environment variables:

1. Di Vercel Dashboard:
   → Settings → Environment Variables

2. Atau via CLI:
   vercel env add NAMA_VARIABLE

═══════════════════════════════════════════════════════════════

🌐 CUSTOM DOMAIN (OPSIONAL):

Jika punya domain sendiri (misal: usahababulu.com):

1. Di Vercel Dashboard:
   → Settings → Domains
   → Add Domain

2. Ikuti instruksi untuk setting DNS

3. Atau via CLI:
   vercel domains add usahababulu.com

❓ TROUBLESHOOTING:

Q: Build failed?
A: Cek logs di Vercel dashboard
   Pastikan npm run build berhasil di local

Q: Website tidak muncul?
A: Tunggu 1-2 menit setelah deploy
   Clear browser cache (Ctrl + F5)

Q: Foto tidak muncul?
A: Pastikan foto ada di public/images/
   Path harus /images/nama-foto.jpg

Q: Vercel login tidak bisa?
A: Gunakan cara 2 (lewat website)
   Lebih mudah dan tidak perlu CLI
