🔄 AUTO DEPLOY AKTIF!

Setiap kali Anda push ke GitHub, website otomatis update!

Cara update:
1. Edit file (misal: ganti nomor WhatsApp)
2. git add .
3. git commit -m "Update nomor WA"
4. git push

→ Vercel otomatis deploy dalam 1-2 menit! ✨
