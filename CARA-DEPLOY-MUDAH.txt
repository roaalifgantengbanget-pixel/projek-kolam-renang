📱 CARA 1: LEWAT WEBSITE (PALING MUDAH!) ⭐ REKOMENDASI

1. Buka browser, ke: https://vercel.com

2. Klik "Sign Up" (atau "Login" jika sudah punya akun)

3. Pilih "Continue with GitHub"
   → Login dengan akun GitHub Anda

4. Setelah login, klik tombol "Add New..."
   → Pilih "Project"

5. Anda akan lihat list repository GitHub
   → Cari: "projek-kolam-renang"
   → Klik tombol "Import" di sebelahnya

6. Vercel akan auto-detect Next.js
   Framework Preset: Next.js ✓
   Root Directory: ./
   Build Command: npm run build ✓
   Output Directory: .next ✓
   
   → Langsung klik "Deploy" (jangan ubah apa-apa)

7. Tunggu 1-2 menit...
   ⏳ Installing dependencies...
   ⏳ Building...
   ⏳ Deploying...

8. SELESAI! 🎉
   ✅ Deployment Complete!
   
   Anda akan lihat:
   🎊 Congratulations!
   
   Link website: https://projek-kolam-renang.vercel.app

9. Klik link tersebut untuk buka website Anda!

═══════════════════════════════════════════════════════════════

💻 CARA 2: LEWAT COMMAND LINE (UNTUK YANG SUKA CLI)

1. Buka Command Prompt atau PowerShell

2. Masuk ke folder project:
   cd "C:\Users\Administrator\Desktop\adrian hitam\nextjs-usaha"

3. Login ke Vercel:
   vercel login
   
   → Browser akan terbuka
   → Login dengan GitHub
   → Kembali ke terminal

4. Deploy:
   vercel
   
   Jawab pertanyaan:
   ? Set up and deploy? Y
   ? Which scope? [Pilih account Anda]
   ? Link to existing project? N
   ? What's your project's name? projek-kolam-renang
   ? In which directory is your code located? ./
   
5. Deploy ke production:
   vercel --prod

6. SELESAI! 🎉
   Link akan muncul di terminal

❓ TROUBLESHOOTING:

Q: Build failed?
A: 1. Cek apakah npm run build berhasil di local
   2. Lihat error di Vercel dashboard → Deployments → Logs

Q: Website tidak muncul?
A: 1. Tunggu 1-2 menit setelah deploy
   2. Clear browser cache (Ctrl + Shift + R)
   3. Coba buka di incognito mode

Q: Foto tidak muncul?
A: 1. Pastikan foto ada di folder public/images/
   2. Path harus /images/nama-foto.jpg (bukan images/)
   3. Redeploy: vercel --prod

Q: Vercel login tidak bisa?
A: Gunakan CARA 1 (lewat website)
   Lebih mudah dan tidak perlu CLI
