🚀 CARA MENJALANKAN:

1. Masuk ke folder proyek:
   cd nextjs-usaha

2. Jalankan development server:
   npm run dev

3. Buka browser:
   http://localhost:3000

4. Build untuk production:
   npm run build
   npm start

OPSI 1 - GitHub CLI (Paling Mudah):
   1. Install: https://cli.github.com/
   2. Login: gh auth login
   3. Push: git push -u origin main

OPSI 2 - Personal Access Token:
   1. Buat token: https://github.com/settings/tokens
   2. Set URL: git remote set-url origin https://TOKEN@github.com/roaalifgantengbanget-pixel/orang-hitam.git
   3. Push: git push -u origin main

OPSI 3 - Upload Manual:
