📝 PERUBAHAN:

1. UNINSTALL Tailwind v4:
   npm uninstall @tailwindcss/postcss tailwindcss

2. INSTALL Tailwind v3:
   npm install -D tailwindcss@3 postcss autoprefixer

3. UPDATE postcss.config.mjs:
   SEBELUM:
   plugins: {
     "@tailwindcss/postcss": {},
   }

   SESUDAH:
   plugins: {
     tailwindcss: {},
     autoprefixer: {},
   }

4. UPDATE app/globals.css:
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   @layer base {
     body {
       font-family: 'Inter', sans-serif;
     }
   }

   @layer components {
     .hero-pattern { ... }
     .fade-in { ... }
   }
