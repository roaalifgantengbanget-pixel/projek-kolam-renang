🚀 LANGKAH SELANJUTNYA: DEPLOY KE VERCEL

1. Buka: https://vercel.com

2. Klik "Sign Up" atau "Login"
   → Pilih "Continue with GitHub"

3. Setelah login, klik "Add New..."
   → Pilih "Project"

4. Import Repository:
   → Cari: roaalifgantengbanget-pixel/orang-hitam
   → Klik "Import"

5. Configure Project:
   Framework Preset: Next.js (otomatis terdeteksi)
   Root Directory: ./
   Build Command: npm run build (otomatis)
   Output Directory: .next (otomatis)
   
   → Klik "Deploy"

6. Tunggu 1-2 menit...

7. SELESAI! 🎉
   Website Anda akan online dengan domain gratis seperti:
   https://orang-hitam.vercel.app
   atau
   https://orang-hitam-xxx.vercel.app

🔄 AUTO DEPLOY:

4. git push
5. Vercel otomatis deploy! ✨
